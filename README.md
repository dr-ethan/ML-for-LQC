This repository contains the code developed for my BSc project, Machine Learning for Lattice Quantum Chromodynamics (LQCD). The aim of the project is to use machine learning to accurately predict the observables of three-point correlation functions using the observables of two-point correlation functions as training data.

Accurately predicting three-point correlation functions in this way has the potential to significantly reduce the computational cost of LQCD calculations. Since these calculations typically require access to expensive supercomputing resources, a successful model could reduce reliance on supercomputers, making this type of research more accessible to a wider range of researchers and institutions.
